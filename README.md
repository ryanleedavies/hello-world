## Using on Mobile

You can browse and interact with this repository on your phone using the GitHub mobile app or a mobile browser:

### GitHub Mobile App (Recommended)
1. Install the **GitHub** app from the [App Store](https://apps.apple.com/app/github/id1477376905) (iOS) or [Google Play](https://play.google.com/store/apps/details?id=com.github.android) (Android).
2. Sign in to your GitHub account.
3. Search for this repository or navigate to it from your profile.
4. From there you can view files, open issues, review pull requests, and more.

### Mobile Browser
1. Open your phone's browser and go to [github.com](https://github.com).
2. Sign in and navigate to this repository.
3. GitHub's mobile web interface lets you browse code, edit files, and manage issues and pull requests.

### Editing Files on Mobile
1. Navigate to the file you want to edit (e.g. `README.md`).
2. Tap the **pencil icon** to enter edit mode.
3. Make your changes and commit directly from your phone.
